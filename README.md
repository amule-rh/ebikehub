# EBikeHub

Premium bilingual e-bike affiliate/content site. Spanish (`/es`) is the primary language; English lives under `/en`.

## Run
npm install
npm run dev

## Build
npm run build

## Structure
- `/es` — primary Spanish home
- `/en` — English version
- Category and editorial pages are handled by the localized catch-all route.
- Range calculator is client-side and requires no API.

Before publishing affiliate claims or product prices, verify current retailer terms, stock and specifications.
