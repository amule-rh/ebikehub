# EBikeHub

Next.js 15 bilingual e-bike affiliate starter. Includes ES/EN home pages, SEO-friendly guide routes, comparisons, category architecture, responsive design and a range-calculator interface.

## Run
npm install
npm run dev

## Deploy
Import into Vercel. Replace the placeholder domain in sitemap/robots when the final domain is known. Add verified affiliate URLs only after joining the relevant programs.

Product specifications in this starter are placeholders for the site structure and should be verified against official sources before publication.
